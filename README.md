# 🌍 Translate App

Modern, responsive, kullanıcı dostu ve dinamik bir dil çeviri uygulaması. Bu proje; kullanıcıların farklı diller arasında hızlı ve sorunsuz çeviri yapabilmesini, kaynak ve hedef dilleri kolayca yönetebilmesini sağlamak amacıyla geliştirilmiştir.

## ✨ Özellikler

* Geniş dil seçenekleri arasında anında geçiş imkanı.
* Arama yapılabilen ve kullanıcı deneyimini artıran modern açılır menüler.
* Çeviri metinlerinin, seçilen dillerin ve API yanıtlarının güvenli ve ölçeklenebilir bir şekilde yönetilmesi.
* Çeviri servisleriyle güvenli ve performanslı HTTP iletişim.
* Mobil uyumlu, şık ve sade tasarım.
* Arayüzü zenginleştiren modern ve hafif vektörel ikonlar.

## 🛠️ Kullanılan Teknolojiler

Projede geliştirme sürecini optimize etmek ve modern standartları yakalamak için aşağıdaki kütüphane ve teknolojiler tercih edilmiştir:

* React
* Redux Toolkit & React Redux
* Axios
* React-Select
* Tailwind CSS
* Lucide React
